# Devoirs

Ce dossier contient les exercices hebdomadaires, les travaux à faire et les petites séries de problèmes du cours de DSP.

## Objectif

Utilisez ce dossier pour :
- pratiquer les concepts abordés en cours et dans les notebooks
- compléter des travaux structurés
- renforcer les techniques de traitement du signal et d’analyse en Python
- préparer les évaluations intermédiaire et pratique

## Méthode de travail recommandée

1. Revoyez le sujet du cours et le notebook associé.
2. Complétez les exercices demandés dans le dossier ou fichier de la semaine correspondante.
3. Validez vos résultats avec les exemples du notebook.
4. Soumettez la sortie demandée sous forme de script Python, notebook ou rapport.

## Organisation

Ajoutez les fichiers de devoirs ici en suivant une convention de nommage claire, par exemple :

- devoir_semaine_01.ipynb
- devoir_semaine_02.py
- assignment_echantillonnage.pdf

## Sorties attendues

Selon la semaine, les livrables peuvent inclure :
- scripts Python
- solutions sous forme de notebook
- graphiques et résultats d’analyse
- courtes explications écrites

## Remarques

Gardez votre code bien commenté et clairement structuré pour que la logique derrière chaque opération DSP soit facile à suivre.
