# Homework

This folder contains weekly exercises, assignments, and short problem sets for the DSP course.

## Purpose

Use this folder to:
- practice the concepts introduced in lectures and notebooks
- complete structured assignments
- reinforce signal processing and analysis techniques in Python
- prepare for the intermediate and practical evaluations

## Recommended workflow

1. Review the relevant lecture topic and notebook.
2. Complete the assigned exercises in the corresponding week folder or file.
3. Validate your results with the notebook examples.
4. Submit the requested output as a Python script, notebook, or report.

## Organization

Add homework files here using a clear naming convention, for example:

- hw_week_01.ipynb
- hw_week_02.py
- assignment_sampling.pdf

## Expected outputs

Depending on the week, outputs may include:
- Python scripts
- notebook solutions
- plots and analysis results
- short written explanations

## Notes

Keep your code well-commented and clearly labeled so that the reasoning behind each DSP operation is easy to follow.
