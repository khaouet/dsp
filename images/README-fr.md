# Images

Ce dossier contient les schémas, graphiques, captures d’écran et ressources visuelles utilisées dans le cours.

## Objectif

Utilisez ce dossier pour :
- des graphiques de signaux
- des courbes de réponse fréquentielle
- des schémas de filtres
- des schémas de blocs
- des captures d’écran et visuels de laboratoire

## Organisation recommandée

Regroupez les images par thème ou par semaine, par exemple :

- echantillonnage/
- convolution/
- fft/
- filtres/
- stm32/

## Remarques

Gardez les noms de fichiers cohérents pour qu’ils soient faciles à référencer dans les notebooks, diapositives et rapports.
