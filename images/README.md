# Images

This folder stores diagrams, plots, screenshots, and visual resources used in the course.

## Purpose

Use this folder for:
- signal plots
- frequency response graphs
- filter diagrams
- block diagrams
- screenshots and lab visuals

## Suggested organization

Group images by topic or week, for example:

- sampling/
- convolution/
- fft/
- filters/
- stm32/

## Notes

Keep image files named consistently so they are easy to reference from notebooks, slides, and reports.
