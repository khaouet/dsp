# Lectures

This folder is intended for lecture materials, slide decks, and supporting notes used throughout the DSP course.

## Purpose

Use this folder to store:
- lecture slides
- additional note files
- conceptual explanations
- formulas and derivations
- diagrams and visual summaries

## Suggested structure

Organize content by week or topic, for example:

- week_01_introduction/
- week_02_complex_signals/
- week_04_convolution/
- week_08_fft/

## Recommended use

Before each class or lab session, review the related lecture content and matching notebook examples in the repository.

## Notes

This folder should contain the instructor-facing teaching materials and the student-facing lecture notes used to explain the DSP topics in the syllabus.
