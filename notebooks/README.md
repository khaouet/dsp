# Notebooks

This folder contains the Jupyter notebooks used throughout the DSP course.

## Purpose

The notebooks are the main practical learning materials for the course. They are used to:
- explain theoretical concepts visually
- experiment with signal generation and processing
- test algorithms in Python
- plot and analyze frequency-domain results
- support lectures, workshops, and assignments

## Recommended workflow

1. Read the related syllabus topic or lecture notes.
2. Open the matching notebook for the week.
3. Run the cells in order.
4. Modify the examples to test your own signals or parameters.
5. Use the results to complete homework and projects.

## Notebook naming convention

Files are organized by week or topic, for example:

- dsp_notes_week01.ipynb
- dsp_notes_week02.ipynb
- dsp_notes_week03.ipynb
- dsp_week1.ipynb

## Typical notebook contents

- definitions and explanations
- Python code examples
- plots and visualizations
- numerical experiments
- short exercises

## Notes

Use the notebooks as the primary practical companion to the course content. They are designed to reinforce the theory through interactive experimentation.
