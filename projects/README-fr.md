# Projets

Ce dossier est destiné aux projets étudiants et aux livrables du projet final.

## Objectif

Utilisez ce dossier pour :
- proposer des projets finaux
- rédiger des rapports de projet
- stocker le code source et les notebooks
- conserver des jeux de données ou des fichiers audio
- préparer des supports de présentation

## Types de projets courants

Les exemples peuvent inclure :
- traitement audio
- filtrage de signaux ECG ou biomédicaux
- analyse spectrale basée sur la FFT
- implémentation DSP temps réel sur STM32
- réduction de bruit et extraction de caractéristiques de capteurs

## Structure recommandée

Organisez chaque projet dans un dossier séparé :

- nom_projet/
  - rapport.md
  - notebook.ipynb
  - code/
  - donnees/
  - resultats/

## Remarques

Le projet final doit démontrer à la fois la compréhension théorique et la mise en pratique du DSP.
