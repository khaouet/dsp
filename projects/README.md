# Projects

This folder is intended for student projects and capstone deliverables.

## Purpose

Use this folder for:
- final project proposals
- project reports
- source code and notebooks
- datasets or wave files
- presentation materials

## Typical project types

Examples may include:
- audio signal processing
- ECG or biomedical signal filtering
- FFT-based spectrum analysis
- real-time DSP implementation on STM32
- sensor signal denoising and feature extraction

## Suggested structure

Organize each project as a separate folder:

- project_name/
  - report.md
  - notebook.ipynb
  - code/
  - data/
  - results/

## Notes

The final project should demonstrate both theoretical understanding and practical DSP implementation.
