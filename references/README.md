# References

This folder contains supporting references, articles, documentation, and reading material for the DSP course.

## Purpose

Use this folder to keep:
- textbook references
- technical papers
- datasheets and application notes
- CMSIS-DSP documentation
- useful external links and summaries

## Examples of useful material

- Discrete-time signal processing textbooks
- FFT and filter design references
- STM32 and CMSIS-DSP documentation
- research papers and application notes

## Notes

Keep references organized by topic and date so they remain easy to search and reuse.
