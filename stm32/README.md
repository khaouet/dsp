# STM32 DSP

This folder is reserved for microcontroller and embedded DSP work based on STM32 devices.

## Purpose

Use this folder for:
- firmware examples
- CMSIS-DSP implementations
- STM32CubeIDE configuration notes
- embedded signal processing experiments
- hardware-related project files

## Typical content

You may add:
- project folders
- C code examples
- linker and build configuration files
- notes on sampling, filtering, and real-time DSP

## Suggested workflow

1. Review the related DSP concept in the course materials.
2. Implement the algorithm in Python or pseudocode first.
3. Port the solution to C for STM32.
4. Validate the result on hardware or in simulation.
