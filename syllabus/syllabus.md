# Digital Signal Processing (DSP) Training Program

## Duration

**10 Weeks**

## Course Organization

-   **Lecture:** 1.5 hours every week (15 hours total)
-   **Workshop (Hands-on Lab):** 3 hours every two weeks (5 workshops =
    15 hours)
-   **Homework / Assignments:** 2 hours every week (20 hours total)

**Total:** **50 hours**

## Workshops

1.  Python & Signal Generation
2.  Discrete Signals and Convolution
3.  FFT and Spectrum Analysis
4.  Digital Filter Design
5.  Final DSP Project

## Learning Outcomes

By the end of the course, students will be able to:

-   Explain DSP fundamentals.
-   Perform sampling and frequency-domain analysis.
-   Design FIR and IIR filters.
-   Analyze signals using FFT.
-   Develop DSP applications in Python.
-   Implement DSP algorithms on STM32 using CMSIS-DSP.
-   Complete an end-to-end DSP project.
