# Ateliers

Ce dossier contient les activités de laboratoire pratiques et les ateliers du cours de DSP.

## Objectif

Les ateliers sont conçus pour favoriser l’apprentissage appliqué à travers :
- la génération de signaux en Python
- le tracé et l’analyse de signaux
- la convolution et la conception de filtres
- l’FFT et l’analyse spectrale
- des exemples de DSP embarqué avec STM32/CMSIS-DSP

## Structure type d’un atelier

Chaque atelier peut inclure :
- un objectif bref
- une explication technique
- des exemples de code
- des exercices à réaliser
- des étapes de validation ou des graphiques attendus

## Organisation recommandée

Utilisez un dossier ou un fichier par atelier, par exemple :

- atelier_01_signaux_python/
- atelier_02_convolution/
- atelier_03_analyse_fft/
- atelier_04_conception_filtres/
- atelier_05_dsp_stm32/

## Remarques

Les ateliers complètent les supports de cours et doivent être réalisés avant ou en parallèle des travaux associés.
