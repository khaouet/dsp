# Workshops

This folder contains hands-on lab activities and practical workshops for the DSP course.

## Purpose

Workshops are designed to support applied learning through:
- Python signal generation
- signal plotting and analysis
- convolution and filter design
- FFT and spectral analysis
- embedded DSP examples with STM32/CMSIS-DSP

## Typical workshop structure

Each workshop may include:
- a brief objective
- a technical explanation
- code examples
- exercises to complete
- validation steps or expected plots

## Suggested organization

Use one folder or file per workshop, such as:

- workshop_01_python_signals/
- workshop_02_convolution/
- workshop_03_fft_analysis/
- workshop_04_filter_design/
- workshop_05_stm32_dsp/

## Notes

The workshops complement the lecture materials and should be completed before or alongside the related assignments.
